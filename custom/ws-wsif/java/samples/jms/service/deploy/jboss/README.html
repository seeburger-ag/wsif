Web Services Invocation Framework:
Deploying the EJB Sample in a JBoss environment

  • Deploying the sample: We have included in this directory a pre-packaged jar that contains the compiled beans and the configuration files required by JBoss. All you need to deploy to JBoss is to drop this serviceavailability JAR file for JBoss (assuming you use the default server configuration) into server/default/deploy under your JBoss server installation, and start your server. This has been tested with JBoss version 3.0.4 running on Windows 2000, with the sample client running on Windows 2000 and using WSIF in a Java 1.4.1 environment.
  • Configuring the WSDL: Under the <port> section of the ServiceAvailability WSDL file, stick in the following deployment information, which is specific to deployment in a JBoss environment: 

            <!-- JBoss specific JMS endpoint -->
	<jms:address destinationStyle="queue"
		     jndiDestinationName="queue/A"
		     jndiConnectionFactoryName="ConnectionFactory"
                     initialContextFactory="org.jnp.interfaces.NamingContextFactory"
	             jndiProviderURL="localhost"/>
