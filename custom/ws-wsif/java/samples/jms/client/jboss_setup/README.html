Web Services Invocation Framework:
Setting up the EJB Sample in a JBoss client environment

  • Setting up the classpath: We have written a script to set up the client environment. To run this script, make sure you are in your base WSIF directory (the one that contains the classpath.bat script. Set the variable JBOSS_HOME to point to your JBoss installation. From there, run the command samples\ejb\client\jboss_setup\jboss.bat. This sets up the entire client classpath required to run the sample using JBoss client JAR files.
